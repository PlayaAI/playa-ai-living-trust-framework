# Implementation Resources

Implementation resources translate the Framework into practical community and organizational workflows. They do not replace legal advice, cultural authority or community participation.

## Current alpha resources

- [Privacy notice template](../templates/privacy-notice.md) — Data Stewardship Profile disclosure structure
- [AI data-use addendum](../templates/ai-addendum.md) — Data Stewardship Profile record for material AI uses

## Co-design pipeline

The following resources will be drafted and tested through On Our Own Terms:

1. **Community AI decision guide** — convening, authority, options, dissent and decision record
2. **AI installation disclosure card** — visible AI role, data use, choice, human contact and incident route
3. **Artist consent and authorship template** — permitted uses, training, credit, provenance, compensation and withdrawal
4. **Cultural archive stewardship checklist** — community authority, relational data, access, model use and return of learning

These items remain planned until a named owner, community review process, pilot context and evidence standard are recorded.
